# Security policy

## Supported version

Security fixes are applied to the latest version on the `main` branch and to the current production deployment.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting feature on this repository when it is available. Otherwise, contact the repository owner through the GitHub profile and ask for a private reporting channel.

Include reproduction steps, affected URLs or versions, and the impact you observed. Do not access data that does not belong to you, disrupt the service, or perform denial-of-service testing.
